# PageDots
A pager for Home when today has more than one look. It sits centred below the look caption, just above the dock.

Provide `count`, `value` (the current index) and an optional `label`.

- Dots are 6px `cream-400`. The current dot stretches to a 16px `ink` capsule, animated over 0.2s.
- Hide the pager when there is only one page.
