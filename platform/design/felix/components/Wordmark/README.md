# Wordmark
The Robes wordmark: the name typeset in Cormorant 400 at 17px, uppercase, tracked 0.34em, in `ink`.

There is no drawn logo — the wordmark is type. Render it with this component (or the `wordmark` text style); never outline, recolor, or set it in Inter.

- One per screen, top-left in the nav.
- On imagery use `cream` only when the photo is dark enough for 4.5:1.
- `children` overrides the text only for localized builds.
