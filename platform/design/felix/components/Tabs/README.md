# Tabs
An underline tab rail for switching views inside a look or page.

Provide `items` (labels), `value` (the selected one) and `onChange(label)`.

- 44px tall, 9px tracked uppercase labels, 16px side padding, left-aligned.
- Selected: `ink` text with a 1.5px `ink` underline; others `ink-soft`.
- The rail has a 0.5px `rule` baseline. Two to four tabs; never icons.
